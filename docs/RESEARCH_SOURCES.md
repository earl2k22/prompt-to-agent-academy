# Official research and recommended study resources

Reviewed for the initial academy project on 2026-11-13. External vendor docs change; re-check links and advice before relying on current behavior.

## Recommended reading order
1. **OpenAI — Prompt Engineering**: https://platform.openai.com/docs/guides/prompt-engineering
   - Establish clear goals, constraints, examples and output design.
2. **Google — Gemini API Prompting Strategies**: https://ai.google.dev/gemini-api/docs/prompting-strategies
   - Compare direct prompting, examples and structured output.
3. **Anthropic — Effective Context Engineering for AI Agents**: https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
   - Treat context as a limited engineering resource.
4. **Anthropic — Building Effective Agents**: https://www.anthropic.com/engineering/building-effective-agents
   - Learn when to prefer simple workflows versus complex orchestration.
5. **Model Context Protocol — Introduction**: https://modelcontextprotocol.io/introduction
   - Learn how AI applications can connect to tools and resources.
6. **OWASP — Prompt Injection**: https://genai.owasp.org/llmrisk/llm01-prompt-injection/
   - Study tool-output trust boundaries and malicious instructions.

## Reading practice
For every guide, note three things:
- One technical term you can define plainly.
- One concrete rule you could apply in a prompt.
- One failure mode or limitation you should test.

## Source integrity
The curriculum synthesizes public engineering guidance, but is original learning material, not an official certification or a copy of vendor documentation. Use authoritative documentation and empirical testing when features evolve.
